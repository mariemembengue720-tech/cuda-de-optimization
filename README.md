# Optimisation sous CUDA : DE & PSO

Ce dépôt contient les implémentations et comparaisons des algorithmes d'optimisation en C++/CUDA (sur CPU et GPU).

## Structure du dépôt

* **`DE/`** : Implémentation, codes sources et résultats pour l'algorithme d'Évolution Différentielle (*Differential Evolution*).
* **`PSO/`** : Implémentation, codes sources et résultats pour l'algorithme d'Optimisation par Essaim Particulaire (*Particle Swarm Optimization*).
